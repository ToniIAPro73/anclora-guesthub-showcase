# Portfolio notice

This repository presents a reduced case study of Anclora GuestHub.

The operational source code is maintained separately and is not distributed
through this public repository.

The public material intentionally excludes:

- production source code (Next.js application, API routes, Prisma schema);
- SES.HOSPEDAJES integration and submission logic;
- XML generation and validation implementation details;
- authentication and role-based access control implementation;
- database schemas and migrations;
- infrastructure and deployment configuration;
- real guest, reservation or commercial information.

Screenshots included in this repository were copied verbatim from the
operational product's own user manual (`docs/manual/screenshots/`). All data
visible in them is synthetic or demo data (e.g. `demo@anclora.local`,
reservation reference `DEMO-2026-0001`, masked documents and IBAN) — never
real guests or reservations.

All diagrams are conceptual and intended solely to demonstrate software
architecture and product-development experience.
